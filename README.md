# Student Marks Analyzer

A Python-based Student Marks Analyzer developed to manage and analyze student academic records.

## Features

* Add student details
* Display all student records
* Search student by roll number
* Calculate total marks
* Calculate average marks
* Generate grades automatically
* Find subject-wise maximum scores
* Identify the class topper
* Analyze subject consistency using NumPy
* Save student records to a CSV file

## Technologies Used

* Python
* NumPy
* CSV File Handling
* Object-Oriented Programming (OOP)

## How to Run

1. Download the project files.
2. Install NumPy:

```bash
pip install numpy
```

3. Run the program:

```bash
python student_marks.py
```
